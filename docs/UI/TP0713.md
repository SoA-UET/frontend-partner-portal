# TP-13: Import file kiến thức local (Excel/Word/CSV → DB local)

**Actor:** Nhân viên cập nhật dữ liệu

**Trigger:** Nhấn “Import dữ liệu”

**Tiền điều kiện:** Đã đăng nhập, có file

**Hậu điều kiện:** Dữ liệu từ file được nhập vào DB local

**Luồng cơ bản:**

1. Chọn file
2. Mapping cột
3. Xem preview
4. Nhấn Import
5. Xem báo cáo kết quả

**Luồng thay thế:**

- A1. Dừng import giữa chừng

**Luồng ngoại lệ:**

- E1. File lỗi định dạng
