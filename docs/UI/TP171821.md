# TP-17: Tiếp nhận yêu cầu tư vấn văn bản chuyển từ Core

**Actor:** Tư vấn viên Text Agent

**Trigger:** Nhận thông báo có tin nhắn mới từ Core

**Tiền điều kiện:** Đã đăng nhập, trạng thái Online

**Hậu điều kiện:** Tư vấn viên nhận và trả lời khách hàng

**Luồng cơ bản:**

1. Tin nhắn hiện trong hàng đợi  
2. Nhấn “Nhận tư vấn”  
3. Chat realtime với khách  
4. Kết thúc phiên

**Luồng thay thế:**

- A1. Chuyển yêu cầu cho tư vấn viên khác

**Luồng ngoại lệ:**

- E1. Mất kết nối Core → Phiên tự động offline

# TP-18: Tiếp nhận cuộc gọi thoại chuyển từ Core

**Actor:** Tư vấn viên Voice Agent

**Trigger:** Nhận cuộc gọi ringing từ Core

**Tiền điều kiện:** Đã đăng nhập, trạng thái Ready

**Hậu điều kiện:** Cuộc gọi được kết nối và tư vấn

**Luồng cơ bản:**

1. Điện thoại/webphone reo  
2. Nhấn “Nghe máy”  
3. Nói chuyện trực tiếp  
4. Kết thúc cuộc gọi

**Luồng thay thế:** 0

**Luồng ngoại lệ:**

- E1. Tư vấn viên bận → Tự động vào hàng đợi

# TP-21: Xem lịch sử các phiên tư vấn được chuyển tiếp từ Core

**Actor:** Manager

**Trigger:** Vào menu “Lịch sử chuyển tiếp”

**Tiền điều kiện:** Đã đăng nhập

**Hậu điều kiện:** Hiển thị danh sách các phiên đã từng chuyển

**Luồng cơ bản:**

1. Lọc theo ngày, tư vấn viên, kênh  
2. Click để xem chi tiết (nội dung chat hoặc nghe lại audio)

**Luồng thay thế:** 0

**Luồng ngoại lệ:** 0
