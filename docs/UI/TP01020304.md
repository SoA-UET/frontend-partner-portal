# TP-01: Đăng nhập

**Actor:** Tất cả actor Partner

**Trigger:** Mở trang admin Telcenter Partner

**Tiền điều kiện:** Có tài khoản hợp lệ

**Hậu điều kiện:** Đăng nhập thành công, nhận token và vào dashboard

**Luồng cơ bản:**

1. Nhập username + password  
2. Nhấn Đăng nhập  
3. Hệ thống xác thực  
4. Chuyển đến trang chủ

**Luồng thay thế:**

- A1. Nhấn “Quên mật khẩu” → Nhập email → Nhận link reset

**Luồng ngoại lệ:**

- E1. Sai ≥5 lần → Khóa tài khoản 30 phút
