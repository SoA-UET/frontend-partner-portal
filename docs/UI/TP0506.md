# TP-05: Cấu hình thông tin nhà mạng Partner (tên, lĩnh vực…)

**Actor:** Admin Telcenter Partner

**Trigger:** Vào menu “Cấu hình hệ thống Partner”

**Tiền điều kiện:** Đã đăng nhập vai trò Admin

**Hậu điều kiện:** Thông tin Partner được cập nhật

**Luồng cơ bản:**

1. Chỉnh sửa các trường  
2. Nhấn Lưu

**Luồng thay thế:** 0

**Luồng ngoại lệ:**

- E1. File logo quá lớn

# TP-06: Thiết lập / cập nhật kết nối đến Telcenter Core

**Actor:** Admin Telcenter Partner

**Trigger:** Vào menu “Kết nối Core”

**Tiền điều kiện:** Đã đăng nhập vai trò Admin

**Hậu điều kiện:** Kết nối Core hoạt động bình thường

**Luồng cơ bản:**

1. Nhập URL Core, API Key, Partner ID  
2. Nhấn “Test kết nối”  
3. Nếu OK → Nhấn Lưu

**Luồng thay thế:** 0

**Luồng ngoại lệ:**

- E1. Test thất bại → Không cho lưu
