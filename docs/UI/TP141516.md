# TP-14: Tạo bản cập nhật dữ liệu mới (update)

**Actor:** Nhân viên cập nhật dữ liệu

**Trigger:** Nhấn “Tạo bản cập nhật mới”

**Tiền điều kiện:** Đã đăng nhập, kết nối Core OK

**Hậu điều kiện:** Bản cập nhật được tạo với trạng thái Draft

**Luồng cơ bản:**

1. Chọn dữ liệu cần gửi (FAQ, kiến thức, file…)  
2. Nhập mô tả phiên bản  
3. Nhấn Tạo bản nháp (Draft)

**Luồng thay thế:** 0

**Luồng ngoại lệ:** 0

# TP-15: Xóa bản cập nhật đang ở trạng thái Draft

**Actor:** Nhân viên cập nhật dữ liệu

**Trigger:** Nhấn “Xóa” trên bản nháp

**Tiền điều kiện:** Bản đang Draft

**Hậu điều kiện:** Bản nháp bị xóa

**Luồng cơ bản:**

1. Confirm → Xóa

**Luồng thay thế:**

- 1. Cancel → Đóng dialog và không xóa

**Luồng ngoại lệ:** 0

# TP-16: Gửi bản cập nhật lên Telcenter Core

**Actor:** Nhân viên cập nhật dữ liệu

**Trigger:** Nhấn “Gửi lên Core” trên bản nháp

**Tiền điều kiện:** Bản nháp đã hoàn thiện, kết nối Core OK

**Hậu điều kiện:** Bản cập nhật được gửi đi, trạng thái = Waiting for approval

**Luồng cơ bản:**

1. Nhấn “Gửi lên Core”  
2. Confirm  
3. Hệ thống đẩy qua API → Core nhận được

**Luồng thay thế:** 0

**Luồng ngoại lệ:**

- E1. Core từ chối → Hiển thị lý do
